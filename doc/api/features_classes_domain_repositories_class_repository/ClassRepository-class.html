ClassRepository

ClassRepository class abstract interface

Contrato de dominio responsable de orquestar la lógica de clases y membresías.

El repositorio actúa como capa anti-corrupción entre los Cubits y los servicios de acceso a datos (Firestore, helpers de fan-out, etc.). Ningún widget o Cubit debe comunicarse con servicios directamente.
