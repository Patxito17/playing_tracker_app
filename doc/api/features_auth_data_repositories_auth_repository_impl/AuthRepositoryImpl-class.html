AuthRepositoryImpl class

Implementación concreta del AuthRepository usando Firebase Auth + Firestore.

Accede a las colecciones teachers y students directamente para leer y escribir perfiles. Los proveedores pueden inyectarse en el constructor para facilitar las pruebas unitarias.
