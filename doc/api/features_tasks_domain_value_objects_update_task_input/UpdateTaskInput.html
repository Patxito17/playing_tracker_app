UpdateTaskInput = ({String? attachmentUrl, String? description, DateTime? dueDate, int? durationSuggested, bool? isActive, String taskId, String? title})

Record que encapsula los datos necesarios para actualizar una tarea.

Este value object permite realizar actualizaciones parciales de una tarea garantizando que siempre exista un identificador válido y al menos un campo modificable.

Campos:

  • taskId: Identificador único de la tarea a actualizar (obligatorio).
  • title: Nuevo título opcional (mínimo 3 caracteres si se proporciona).
  • description: Nueva descripción opcional.
  • durationSuggested: Nueva duración sugerida en segundos (> 0 si se proporciona).
  • attachmentUrl: Nueva URL de material de referencia opcional. Pasar cadena vacía para eliminar la URL existente.
  • dueDate: Nueva fecha de vencimiento opcional.
  • isActive: Permite archivar/activar la tarea.
