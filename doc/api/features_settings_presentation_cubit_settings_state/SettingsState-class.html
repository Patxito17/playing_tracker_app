SettingsState

SettingsState class

Estado inmutable de ajustes de usuario gestionado por SettingsCubit.

Agrupa las tres categorías de preferencias: apariencia (tema y color), idioma y estado de tutoriales. Todas las modificaciones crean una nueva instancia mediante copyWith.
