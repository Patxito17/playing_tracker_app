AuthCubit

AuthCubit class

Cubit responsable de manejar el estado de autenticación de la app.

Utiliza HydratedCubit para persistir el rol y el userId entre reinicios, evitando mostrar pantallas de login innecesarias cuando la sesión sigue vigente.
